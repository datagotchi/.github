## 🛡️ The Thesis: Countering the Digital Enclosure

Much like early public commons were enclosed by private interests, the open web has been siloed into proprietary platforms that extract user value and trap operational data. 

We build **local-first, sovereign tools** that return data ownership, sensemaking, and operational control to individuals and working groups.

### The LGPL Open-Source Strategy
We license our core libraries and primitives under the **GNU Lesser General Public License (LGPL)**. 

* **Anti-Enclosure Shield:** LGPL enforces strong copyleft on core library modifications—preventing tech monopolies from enclosing our foundational code inside closed, proprietary software.
* **Modular Freedom:** It allows developers, small teams, and open-source contributors to dynamically link our libraries into broader projects without triggering viral licensing constraints on their own applications.

## ⚡ Core Engineering Principles

1. **Deterministic Logic Over Token Waste:** Use AI strictly where cost-effective. Rely on clean schemas, deterministic scripts, and explicit logic over unvalidated LLM prompts.
2. **Low-Entropy Interfaces:** Design tools that reduce cognitive overload, respect user sensory boundaries, and eliminate arbitrary box-checking.
3. **Data Sovereignty First:** Ensure raw data remains accessible, exportable, and fully owned by the user—never trapped behind SaaS paywalls.
